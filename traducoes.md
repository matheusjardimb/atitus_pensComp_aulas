| Palavra-chave | Tradução / Significado em PT                                |
|---------------|-------------------------------------------------------------|
| `False`       | Falso (valor booleano)                                      |
| `None`        | Nenhum (ausência de valor)                                  |
| `True`        | Verdadeiro (valor booleano)                                 |
| `and`         | E lógico                                                    |
| `as`          | Como (usado em importações e contextos)                     |
| `assert`      | Afirma (verificação para debug)                             |
| `break`       | Quebra (sai de laço de repetição)                           |
| `continue`    | Continuar (pula para próxima iteração de laço)              |
| `def`         | Definir (define uma função)                                 |
| `del`         | Deletar (remove referência a objeto)                        |
| `elif`        | Senão se                                                    |
| `else`        | Senão                                                       |
| `for`         | Para (laço de repetição)                                    |
| `from`        | De (usado em importações)                                   |
| `global`      | Global (declara variável como global)                       |
| `if`          | Se (condicional)                                            |
| `import`      | Importar                                                    |
| `in`          | Em (verifica pertencimento ou itera sobre sequência)        |
| `is`          | É (verifica identidade de objetos)                          |
| `lambda`      | Lambda (função anônima)                                     |
| `match`       | Casar (comparação de padrões - semelhante a switch)         |
| `not`         | Não (negação lógica)                                        |
| `or`          | Ou lógico                                                   |
| `pass`        | Passar (bloco vazio, faz nada)                              |
| `return`      | Retornar (valor de uma função)                              |
| `while`       | Enquanto (laço de repetição)                                |
| `with`        | Com (contexto gerenciado, como abrir arquivos)              |
| `async` *     | Assíncrono (execução não bloqueante)                        |
| `await` *     | Esperar (aguarda resultado assíncrono)                      |
| `class` *     | Classe (define uma classe)                                  |
| `except` *    | Exceto (tratamento de exceções)                             |
| `finally` *   | Finalmente (executa bloco final de um try)                  |
| `nonlocal` *  | Não local (altera variável de escopo acima, mas não global) |
| `raise` *     | Lançar (erro/exceção)                                       |
| `try` *       | Tentar (início de bloco de tratamento de exceções)          |
| `yield` *     | Produzir (retorna valor em geradores)                       |
